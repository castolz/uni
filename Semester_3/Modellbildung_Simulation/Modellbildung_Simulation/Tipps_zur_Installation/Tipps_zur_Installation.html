Tipps zur Installation der Entwicklungsumgebung zur Vorlesung

Prof. Dr. Thomas Köller – Hochschule Karlsruhe

Im Rahmen der Vorlesung werden Simulationsaufgaben mit Python oder einer Kombination aus Python und OpenModelica gelöst. Vermutlich möchten viele von Ihnen die in der Vorlesung benutzte Software auf ihrem eigenen Laptop installieren. Nachfolgend finden Sie eine ausführliche Installationsanleitung.

Unter https://bwsyncandshare.kit.edu/s/p6TagxcYkL2y6ZJ finden Sie das neueste Environment zur Vorlesung.

Linux

Bei dem heruntergeladenen Environment handelt es sich um ein rootfs (Root Filesystem), das unter Linux direkt verwendet werden kann. Eine Installation ist nicht erforderlich.

  • Erstellen Sie in einem beliebigen Verzeichnis ein Unterverzeichnis mit dem Namen rootfs und entpacken Sie die heruntergeladene .tar-Datei in diesem Verzeichnis.
  • Editieren Sie die Datei enter.sh und ersetzen Sie xy mit Ihrem Usernamen.
  • Beim ersten Aufruf des Enterskripts wird in Ihrem Homeverzeichnis ein Verzeichnis Dokumente/modsimdata erstellt. Dieses wird in Ihr rootfs unter /home/Users/modsim/Dokumente/modsimdata_extern gemountet. Dieses Verzeichnis können Sie als Arbeitsverzeichnis für die Veranstaltung nutzen.
  • Für die beiden benutzten Programme gibt es Shortcuts om, bzw. spy.

Windows

Bei dem heruntergeladenen Environment handelt es sich um ein rootfs (Root Filesystem), das unter Windows mit wsl (Windows Subsystem für Linux) genutzt werden kann.

Einbinden unter Windows:

  • Erstellen Sie zunächst ein Verzeichnis C:\WSL\ModSim.
  • Öffnen Sie die Powershell im Downloadverzeichnis mit admin-Rechten und installieren Sie wsl (wsl.exe --install, anschließend Rechner neu starten.)
  • Öffnen Sie die Powershell im Downloadverzeichnis mit admin-Rechten und geben Sie folgendes ein: wsl --import ModSim C:\WSL\ModSim modsimenvxy.tar (xy durch die Versionsnummer ersetzen.)
  • Durch die Eingabe wsl -d ModSim in der Powershell startet das rootfs im User modsim. Die Windowslaufwerke werden unter /mnt/c, /mnt/d oder /mnt/n (Netzlaufwerk in der Hochschule) gemountet. Sie können deshalb an beliebiger Stelle ein Arbeitsverzeichnis erstellen. Vermeiden Sie aber bitte Sonderzeichen.
  • Für die beiden benutzten Programme gibt es Shortcuts om, bzw. spy.

Test der Installation

Testen Sie Ihre Installation wie folgt:

  • spy eingeben und die Datei /home/modsim/Dokumente/testmodsim/pt1_step.py öffnen.
  • F5 zum Ausführen des Skripts drücken.
  • Im Reiter Plots sollte die Sprungantwort eines PT1-Gliedes erscheinen.
